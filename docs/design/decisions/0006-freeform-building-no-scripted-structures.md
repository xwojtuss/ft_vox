# 0006: Freeform building, no scripted structures

- **Date:** 2026-09-28
- **Status:** Accepted

## Decision

Everything players build, including rockets and ships, is freeform. Machines and small vehicles are multi-block structures. The game never asks for a scripted structure of a fixed shape.

## Why

Freedom to build is a pillar. Switching to "build this specific thing" late in the game would break the rules players learned all game.

## Rejected alternatives

- **Megastructure end goals:** a gate, an orbital ring, a Dyson swarm, a space elevator, a planet-circling railgun, a living ship.
