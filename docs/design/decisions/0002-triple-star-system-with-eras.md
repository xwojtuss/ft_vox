# 0002: A triple star system whose dance creates eras

- **Date:** 2026-09-28
- **Status:** Accepted

## Decision

The game takes place in a triple star system. The stars' dance puts every planet through eras (heat, cold, darkness, radiation, calm), and every planet reacts differently. Details: [world/](../world/).

## Why

- A constantly changing world with nearly unlimited variety, from one simple rule.
- Gives exploration a purpose beyond resources: understanding what makes each planet unique.
- Planets changing colour with the eras is a strong visual identity.

## Rejected alternatives

- **Terraria-style one-time world changes as the main idea** (dormant biosphere, moon breaking into a ring, volcanic winters): kept as possible ideas, but not the core.
- **Harsh eras that force players to leave a planet:** doesn't make sense if native life survives there, and it gets irritating.
