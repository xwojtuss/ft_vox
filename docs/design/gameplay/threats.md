# Threats and combat

- **Combat works like in Factorio:** it supports progress and protects what players build, but it is never the point. There is no final boss.
- **Native fauna reacts to what the players do** (industry, noise, heat, pollution), so the pressure grows out of the players' own expansion.
- The environment itself (eras, atmospheres, radiation) is the main danger.
