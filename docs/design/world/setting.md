# Setting

- The game takes place in a **triple star system**: three suns circling each other in an endless dance.
- The dance never repeats in an obvious way and it constantly changes conditions on every planet (see [eras.md](eras.md)).
- **The orbits are stable enough for life and machines to keep running.** The dance keeps the world changing; it does not destroy it.
- Far out, the dance has been throwing material outward for billions of years, forming the **Debris Belt** at the edge of the system (see [../progression/end-goal.md](../progression/end-goal.md)).
- How the stars move in the engine is described in [../technical/star-system.md](../technical/star-system.md).
