# Star system

Decided in [#78](https://github.com/xwojtuss/ft_vox/issues/78).

- **The stars move on fixed, time-based paths,** not in a real physics simulation.
- The dance **looks** chaotic because it repeats over a very long cycle, but it is fully predictable.
- This keeps saves, multiplayer (every client sees the same sky) and era predictions consistent, and makes "predicting the eras" in the research tree possible.
