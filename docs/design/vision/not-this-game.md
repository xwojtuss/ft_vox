# What the game is not

- **Not story-driven.** No narrator, cutscenes, lore to read or quest book. The research tree is the only guide.
- **Not on a timer.** No deadline, no countdown, no doom clock.
- **Not a boss game.** Combat supports progress; there is no final boss.
- **Not punishing.** No cascades that wipe out a base because of one wrong click (a deliberate difference from Stationeers).
- **Not a factory game at heart.** Automation exists, but players build and maintain systems rather than endless production lines (a deliberate difference from Factorio).
- **Not scripted construction.** No megastructure the game tells you to build in a fixed shape.
